# Блокнот с проверкой орфографии

Проект представляет собой текстовый редактор (блокнот) с встроенной проверкой орфографии для русского и английского языков, а также поддержкой тем оформления.

## Модули проекта

- Интерфейс пользователя: Клиентская часть предоставляет главное окно редактора с текстовым полем, строкой меню и панелью инструментов. Интерфейс должен быть интуитивно понятным и обеспечивать удобную работу с текстом. Предусмотрена поддержка изменения размера окна и масштабирования текста.

- Модуль проверки орфографии (русский язык): Данный модуль обеспечивает проверку орфографии вводимого текста на русском языке в режиме реального времени. Ошибочно написанные слова подчёркиваются красной волнистой линией. Модуль предоставляет список вариантов замены для каждого ошибочного слова через контекстное меню.

- Модуль проверки орфографии (английский язык): Данный модуль обеспечивает проверку орфографии вводимого текста на английском языке в режиме реального времени. Логика работы аналогична модулю проверки русского языка. Предусмотрена возможность одновременной проверки обоих языков при наличии смешанного текста.

- Модуль управления темами оформления: Модуль отвечает за визуальное оформление интерфейса редактора. Предусмотрены как минимум три темы: светлая, тёмная и системная (автоматически подстраивается под настройки ОС). Пользователь может переключать темы через меню настроек без перезапуска приложения.

- Модуль работы с файлами: Данный модуль обеспечивает создание новых документов, открытие существующих файлов с диска и сохранение текущего документа. Поддерживаемые форматы: TXT, RTF. Предусмотрено предупреждение о несохранённых изменениях при попытке закрыть документ.

- Модуль поиска и замены: Модуль предоставляет функционал поиска вхождений заданной строки в тексте и их последовательной или массовой замены на другую строку. Поиск может выполняться с учётом или без учёта регистра символов. Найденные совпадения визуально выделяются в тексте.

- Модуль автодополнения: Модуль предлагает варианты завершения слова во время ввода на основе встроенного словаря и ранее введённых слов. Список подсказок отображается в виде выпадающего меню непосредственно под курсором. Пользователь может принять подсказку нажатием клавиши Tab или отклонить её продолжением ввода.

- Модуль статистики текста: Данный модуль в режиме реального времени отображает в строке состояния количество символов, слов, строк и абзацев в текущем документе. Предусмотрена возможность получения статистики для выделенного фрагмента текста отдельно от всего документа.

- Модуль настроек: Модуль обеспечивает сохранение и загрузку пользовательских предпочтений: выбранная тема, шрифт, размер шрифта, язык проверки орфографии и прочие параметры. Настройки сохраняются в конфигурационном файле и автоматически применяются при следующем запуске приложения.

- Модуль печати: Данный модуль обеспечивает отправку текущего документа на принтер с поддержкой предварительного просмотра. Пользователь может настроить параметры страницы: поля, ориентацию и масштаб. Предусмотрена печать как всего документа, так и выделенного фрагмента.
